# Kimi 额度桌宠 · Kimi Quota Pet

贴在 Windows 桌面右下角的小挂件：Kimi 的拟人角色双手举着一块平板，实时显示你的 **Kimi 会员额度**。
额度每下降一格，她红闪 + 抖动 + 播放打击音，头顶飘出扣减数字；双击她的头会弹出脸部特写。

**不需要 API Key。** Kimi 的会员额度没有对外的开放接口，这个挂件复用了你本机 Kimi 桌面版自己的登录态（只读、只在内存里用），并在桌面版空闲时自己续期。

## 特性

- **真实额度**：直接调 Kimi 桌面版自己用的额度接口，和你在客户端里看到的一致
- **不需要 API Key**：从本地登录态读取，不弹框、不要求你填任何东西
- **自己续期**：桌面版关掉也能继续读（用的是本地 `refresh_token`，不会把桌面版踢下线）
- **四表情差分**：常态 / 扣费忍痛 / 额度见底 / 读不到额度，切换不跳（跨图对齐误差 1px）
- **停靠位置可选**：右键 → 位置 → 左下角 / 右下角 / 不吸附。前两个立刻归位并记住，「不吸附」松手停在原地（只对本次运行有效）
- **夜间换脸**：本机时间 **23:00–06:00** 之间，退避脸从微笑换成「担忧」（左下差分）；扣费忍痛、额度见底、读不到额度三个状态照旧优先，不受影响。时窗可在 `state.ini` 里改（`night` / `nightIn` / `nightOut`）
- **扣费演出**：每 0.01 元（套餐模式为 1%）红闪 + 抖动 + 打击音 + 头顶飘字，0.2 秒一次串成一条
- **点击特写**：双击她的头弹出脸部特写；额度回升（充值/周期重置）也会弹一次
- **断线可见**：读不到额度时平板显示「打开 Kimi 桌面版」+ `--` + 提示点，并只播一次提示音
- **额度两位小数**：套餐模式显示 `71.31 %`（不再是取整的 `71 %`），额外额度照旧两位（`¥6.25`）
- **扣费倒计时**：平板第三行显示距**上一次真实扣费**的时间，从 `05:00` 倒数到 `00:00` 后停住，下次扣费重新开始；离线/读不到额度期间发生的扣费显示 `--`（不猜时间）
- **开箱即用**：双击 `.vbs` 启动，无黑框；自带桌面/开始菜单快捷方式与防重复开机自启
- **隐私**：只读、只调额度查询接口；token 只在内存里用，日志与任何落盘文件都不含 token

## 快速开始

1. 下载本仓库（或 `git clone`），解压到任意目录（路径有中文没问题，**不要放只读位置**）
2. 双击 **`启动Kimi额度宠物.vbs`**
3. 她出现在屏幕**右下角**，默认 454×454（大杯）。右键她 → 菜单

前提：Windows + 系统自带的 PowerShell 5.1；本机装过并登录过 **Kimi 桌面版**（用于取登录态）。

| 操作 | 效果 |
| --- | --- |
| 左键按住拖动 | 移动；松手吸附回右下角 |
| **双击她的头** | 弹出脸部特写（约 1.35 秒） |
| 右键 | 立即刷新额度 / 测试一次扣费 / 演示连续扣费 / 尺寸 / **位置** / 外观 / 声音 / 退出 |
| 双击托盘图标 | 手动触发一次扣费动画 |

尺寸三档（中杯 340 / 大杯 454 / 超大杯 624），声音有开关和五档音量，改完立刻生效并记住。

**位置**（右键 → 位置）：左下角 / 右下角 / 不吸附。前两个立刻归位并记进 `state.ini` 的 `corner=`；「不吸附」只对本次运行有效——松手停在原地、切尺寸只保证不跑出屏幕，重启后回到上次定的那个角。

开机自启：把 `开机自启（防重复）.vbs` 的快捷方式放进 `shell:startup`（本仓库的 `安装说明.md` 有现成命令）。
想看报错：双击 `启动（调试窗口）.cmd`。退出：右键 → 退出。

## 它是怎么读到额度的

```
%APPDATA%\kimi-desktop\Local Storage\leveldb
        │  ① 共享读（不复制、不写入），扫描全部文件与记录，取未过期里 exp 最大的 access_token
        ▼
access_token (JWT, ~15 分钟)
        │  ② 找不到有效 token 时（桌面版空闲/关闭），用本地 refresh_token 自己续期
        │     POST https://auth.kimi.com/api/account.gateway.v1.AuthService/RefreshToken
        │     实测：服务端会换发新 refresh_token，但不会作废旧 token → 桌面版不受影响
        ▼
   POST .../kimi.gateway.membership.v2.MembershipService/GetSubscriptionStats
   Authorization: Bearer <access_token>
        │
        ▼
   ③ 解析出要显示的那个数
```

| 字段 | 含义 | 用途 |
| --- | --- | --- |
| `subscriptionBalance.amountUsedRatio` | 套餐额度已用比例（按会员周期） | 剩余 % = (1 − 已用) × 100 |
| `boosterWallets[].moneyLeft.priceInCents` | 额外额度（Extra Usage）余额，单位分 | 折算成元显示 |
| `notice.tip` | 站内提示（如"套餐已用尽，正在消耗额外额度"） | 写进日志 |
| `ratelimitCode5h / 7d.resetTime` | 5 小时 / 7 天限流窗口重置时间 | 写进日志 |

**展示口径**：套餐还有余量就显示「剩余额度 xx%」；套餐用尽就自动切「额外额度 ¥xx.xx」。
点"立即刷新额度"会立刻拉一次并对齐（不补播动画）；后台每 10 秒核对一次。

**表情与状态**（`sprites/` 下四张，同一姿态、对齐误差 1px）：

| 文件 | 表情 | 什么时候出现 |
| --- | --- | --- |
| `expression_11.png` | 半眯眼从容微笑 | 常态 |
| `expression_22.png` | 闭眼忍痛 + 汗滴 | 正在扣额度（含扣完的 1 秒） |
| `expression_12.png` | 含泪担心 | 额度见底（额外额度 ≤ ¥5 或套餐剩余 ≤ 10%） |
| `expression_21.png` | 半垂眼死鱼眼 | 读不到额度 |

阈值为常量，想改成 ¥10 或 ¥3 只需改 `kimi_pet.ps1` 里的 `LowQuota`。

## 隐私

- 只读打开 Kimi 桌面版的数据文件（`FileShare.ReadWrite`），**不复制、不写入**任何内容
- 只用两个官方接口：额度查询 + 令牌续期；不消耗额度、不改账号状态
- `access_token` / `refresh_token` 只在本进程内存中使用；**日志与任何落盘文件都不含 token**
- 续期拿到的新令牌**不写回** leveldb，桌面版继续用它自己那份
- 不向任何第三方发送数据

## 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 平板显示「打开 Kimi 桌面版 / --」 | 读不到有效令牌。打开 Kimi 桌面版登录一次即可；桌宠会自己重试并自动恢复 |
| 数字一直不动 | 你最近没用 Kimi。额度只在你实际消耗时下降 |
| 她说"扣费"了但数字没变 | 那是在**演示**（右键 → 测试/演示连续扣费），本地演出，不动真实数据 |
| 双击 `.vbs` 没反应 / 杀软报警 | 界面用系统自带 PowerShell 5.1 画，`.vbs` 只是隐藏黑框，偶尔被误报；改用 `启动（调试窗口）.cmd` 看报错 |
| 卡顿 / 托盘图标消失 | 右键 → 退出，再启动一次 |
| 想换面板位置 / 字号 | 改 `tools/kimi_make_assets.py` 的 `PX/PY/PW/PH` 重跑，把 `panel_quad.txt` 里的新坐标抄进 `kimi_pet.ps1` 的 `qx/qy` |

排错入口是同目录的 **`kimi_pet.log`**（一行一次轮询，写明用了哪种令牌、读到什么、为什么失败）。
格式化的逐行对照表见 [`安装说明.md`](安装说明.md) 第 5 节。

## 二次开发 / 复刻

**换成你自己的角色**：
1. 用 [`art/Kimi差分立绘-生成提示词.md`](art/Kimi差分立绘-生成提示词.md) 里的提示词让图像模型出一张 **2×2 四格图**
   （半身、双手举空白深色平板、纯白背景无道具、四格只有脸不同）
2. `python tools/kimi_grid_check2.py` → 切图、抠图、按平板对齐，并打印新的平板四角坐标
3. `python tools/kimi_make_sprites.py` → 输出 `sprite.png` 与 `sprites/expression_*.png`
4. 把新坐标抄进 `kimi_pet.ps1` 的 `qx/qy`，重启即可

**改数据源**：`kimi_pet.ps1` 里 `ReadKimiToken()` / `FetchKimi()` / `ParseKimiValue()` 三个方法就是全部数据层，
接口地址与目录都可以用环境变量覆盖（`DSHPET_KIMI_URL`、`DSHPET_KIMI_REFRESH_URL`、`DSHPET_KIMI_LS`、`DSHPET_KIMI_TOKEN`），
另外 `DSHPET_POLL_MS`（轮询毫秒）、`DSHPET_SPRITE`、`DSHPET_SOUND_FILE` 等也可调。

**代码来源**：界面外壳（分层窗口、逐像素透明、命中图、托盘菜单、扣费动画与账目模型）移植自
[VKmich16/VK-1](https://github.com/VKmich16/VK-1) 的 Windows 版 v3（MIT），
数据层、显示口径、表情与状态机为本次改写；移植补丁记录在 `tools/port_to_kimi.py`。
